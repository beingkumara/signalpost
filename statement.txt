All that you need to know about Signalpost: Build An Agent That Finds Company Information
What to Build

Give your agent a Norwegian company number. It searches permitted public sources and returns company facts, source links and dates. Make sure each fact belongs to the right company and keep profiles current.

What to Submit

At least 1,000 company profiles
Your repository link
Exact commit hash
One command to run it
Model/API details
Expected run costs
How We Test and Score

Every agent receives the same 100 random companies each day. Find useful information (35 points), match it correctly with evidence (30), update correctly (20), give useful explanations (10), and make it easy to use (5). For coverage, we compare what your agent finds with a checked collection built from submissions and Builderr crawlers.
To qualify: at least 65/100 overall, 21/35 coverage, and all published accuracy, evidence and execution requirements. A material wrong-company publication or fabricated financial value fails the entry. Qualified agents are ranked by their average score across completed daily tests.
Daily limits: 45 minutes, 2,000 outbound requests and $10 in declared external API costs. Development and API usage can incur costs.
Rewards

$2,000 main cash prizes: $1,200 / $500 / $300. Separate $500 JBOX bonus: $250 / $150 / $100 for qualifying agents built with JBOX. Awards require qualification; participation does not guarantee a prize or job.
How to Enter

Build your agent, then email your code and required files to submit@builderr.ai. This online challenge is hosted and evaluated on Builderr. Students and professionals may participate under the published eligibility and team rules. AI coding tools are welcome; working code is required.
